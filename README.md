# Portafolio — Desarrollo Web

Portafolio personal de desarrollo web creado para presentar mi perfil profesional,
habilidades, herramientas y proyectos destacados. El sitio incluye enlaces a
GitHub, descarga de CV, demostraciones de proyectos y medios de contacto.

## Tecnologías y técnicas utilizadas

- HTML5 semántico (`main`, `section`, `footer`)
- CSS3 con metodología BEM
- Flexbox y CSS Grid para alineación y estructura
- Diseño responsivo para escritorio, tablet y dispositivos móviles
- Media queries con puntos de ruptura en `1023px` y `767px`
- Fuentes locales Archivo Black y Open Sans mediante `@font-face`
- Posicionamiento absoluto para elementos decorativos y superpuestos
- Efectos de desenfoque con `filter: blur()` para las elipsis decorativas
- Estados `:hover` con transiciones CSS
- Git y GitHub para control de versiones
- GitHub Pages para publicación del proyecto

## Planes de mejora

- Actualizar el portafolio con nuevos proyectos a medida que avance en mi formación como desarrolladora.
- Incorporar JavaScript para agregar interacciones y funcionalidades dinámicas.
- Mejorar la accesibilidad del sitio siguiendo buenas prácticas de WCAG.
- Optimizar imágenes y recursos para mejorar el rendimiento y los tiempos de carga.
- Mantener actualizado el CV y la información profesional.
